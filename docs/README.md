# Documentación de MyCAD

MyCAD es un proyecto experimental de CAD táctil para Android, inspirado en los flujos de trabajo de Shapr3D. El objetivo es desarrollar una aplicación propia, no copiar código ni recursos propietarios.

## Estados que utilizaremos

- **Propuesto**: idea pendiente de validar.
- **Analizado**: comportamiento documentado a partir de referencias.
- **Diseñado**: flujo y requisitos especificados.
- **Implementado**: código incorporado al repositorio.
- **Compilado**: GitHub Actions finalizó correctamente.
- **Validado en móvil**: comportamiento confirmado mediante prueba real.

No se confundirá un boceto visual con un motor CAD funcional ni una compilación correcta con una prueba en dispositivo.

## Criterio de avance

Cada fase debe tener objetivos, alcance, dependencias, pruebas de aceptación y limitaciones conocidas. Las modificaciones de arquitectura importantes requieren una decisión documentada.
